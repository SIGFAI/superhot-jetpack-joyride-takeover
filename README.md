# Jetpack Joyride Takeover

**superhot** × Jetpack Joyride · visual · idea by the team

Bring Jetpack Joyride into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> Every SUPERHOT enemy now wears a jetpack and my own jet guns turn them into coin showers, until a missile or a zapper crashes the party.

## Install

Install BepInEx 5 (64-bit) into your SUPERHOT folder, then copy the BepInEx folder from this mod's release folder over it and start the game. Hold SPACE in the air to fly and shoot; the mod loads the Warehouse endless level.
